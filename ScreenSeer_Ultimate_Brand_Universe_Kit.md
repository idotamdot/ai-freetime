### Production principles
- All device sizes are export/cropping presets, not independent art commissions; use responsive source masters.
- Platform requirements and social media dimensions change. Maintain versioned presets and verify requirements before release.
- A DTCG JSON file is not by itself a native Figma component library; separate token import from editable component creation.
- Cursor effects should be optional, accessible, and disabled by default on touch-only devices.
- Figma asset import, editable layers, and animation deliverables must be validated before labeling them complete.
- ScreenSeer is the branding studio; its saved identity can be applied across multiple products without modifying the product-specific UX.

### Essential Figma package files
- `figma-tokens.json` — actual DTCG-compatible token values, populated from the approved brand.
- `figma/` — editable SVG masters and valid import-ready component data/files.
- `brand-at-a-glance.pdf` — one-page human cheat sheet.
- `asset-manifest.json` — names, variants, dimensions, status, provenance, licensing.
- `README.md` — installation, reusable identity contract, and import instructions.

**Creative finish line:** Create something worthy of being remembered. The user should never need to know which assets to request.
